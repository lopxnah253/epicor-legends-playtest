# Epicor Legends — Windows Playtest

[**Download the launcher**](https://github.com/lopxnah253/epicor-legends-playtest/releases/latest/download/EpicorLegendsLauncher.zip) · [Latest release](https://github.com/lopxnah253/epicor-legends-playtest/releases/latest) · [Report a bug](https://github.com/lopxnah253/epicor-legends-playtest/issues)

1. Download and extract the launcher ZIP.
2. Open **EpicorLegendsLauncher.exe** and let it install the current build.
3. Choose **Play**. New players create a character after Start Game.

Keep using the launcher for automatic game updates. No GitHub account is needed to download or update. Saves remain separate from game files.

This is an unfinished Windows 10/11 64-bit playtest, not a finished release. A DirectX 11 graphics device is required. If Windows reports a missing VCRUNTIME/MSVCP file, install the [official Microsoft Visual C++ x64 runtime](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist).

## Feedback

Use Report a bug in the launcher, or open an issue above. Include the build version, steps to reproduce, expected result, controller or keyboard type, and a screenshot. A GitHub account is required to submit an issue, but not to play. Do not post passwords or personal information.

This repository distributes game builds and tester instructions. Private development source is not included.
