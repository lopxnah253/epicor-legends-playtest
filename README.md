# Epicor Legends — Open to Play

[**Download the launcher**](https://github.com/lopxnah253/epicor-legends-playtest/releases/latest/download/EpicorLegendsLauncher.zip) · [Latest development update](https://github.com/lopxnah253/epicor-legends-playtest/releases/latest) · [Report a bug](https://github.com/lopxnah253/epicor-legends-playtest/issues)

Epicor Legends is open to play while still in active development. Improvements and new content will continue as the game grows.

1. Download and extract the launcher ZIP.
2. Open **EpicorLegendsLauncher.exe** and let it install the current build.
3. Choose **Play**. New players create a character after Start Game.

Keep using the launcher for automatic game updates. No GitHub account is needed to download or update. Saves remain separate from game files.

For Windows 10/11 64-bit with a DirectX 11 graphics device. If Windows reports a missing VCRUNTIME/MSVCP file, install the [official Microsoft Visual C++ x64 runtime](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist).

## Feedback

Use Report a bug in the launcher, or open an issue above. Include the build version, steps to reproduce, expected result, controller or keyboard type, and a screenshot. A GitHub account is required to submit an issue, but not to play. Do not post passwords or personal information.

This repository distributes game builds and player instructions. Private development source is not included.
